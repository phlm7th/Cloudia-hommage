# Cloudia 수채화 그림 애셋 가이드

`public/art/watercolor/` 폴더에 정해진 이름으로 PNG를 넣으면 앱의 배경 장면이 그 그림으로 바뀝니다.
**모든 파일은 선택입니다.** 없는 파일은 지금처럼 코드가 그린 그림을 대신 쓰므로, 한 장씩 채워 넣어도 됩니다.

## 그림 파일로 받는 것 / 코드가 그리는 것

| 그림 파일로 받기 | 코드가 그리기 (바꿀 필요 없음) |
|---|---|
| 풍경(언덕·집·나무·양·꽃), 구름, 해, 달, 종이 질감 | 하늘색 그라데이션(시간대별), 비, 눈, 별, 번개, 달의 위상 그림자, 밤·노을 색 입히기, 구름 이동 |

## 폴더 구조와 파일명

```
public/art/watercolor/
├─ landscape/
│  ├─ far.png        먼 언덕·숲 띠
│  ├─ mid.png        중간 언덕 + 집 + 나무
│  └─ near.png       앞 언덕 + 흙길 + 꽃 + 양 + 울타리
├─ clouds/
│  ├─ cloud-1.png    흰 뭉게구름 (1~4번, 일부만 있어도 됨)
│  ├─ cloud-2.png
│  ├─ cloud-3.png
│  ├─ cloud-4.png
│  ├─ storm-1.png    회색 비구름 (1~2번)
│  └─ storm-2.png
├─ celestial/
│  ├─ sun.png        번진 해
│  └─ moon.png       보름달
└─ paper.png         종이 결 텍스처
```

파일명은 대소문자까지 정확히 맞춰 주세요. GitHub Pages는 `Far.png`와 `far.png`를 다른 파일로 봅니다.

## 파일별 규칙

### 풍경 `landscape/far.png`, `mid.png`, `near.png`

- **크기: 세 장 모두 1080 × 900 px로 똑같이.**
- 한 캔버스(1080 × 900)에 레이어 3개로 그린 뒤, **레이어마다 캔버스 크기 그대로** 내보내세요. 그래야 앱에서 겹쳤을 때 위치가 맞습니다.
- 그림이 없는 위쪽(하늘 자리)은 **투명**으로 둡니다.
- 앱은 세 장을 `far → mid → near` 순서로 겹치고, 폭을 화면 폭에 맞춘 뒤 화면 **아래쪽에 붙입니다**. 화면이 길면 위쪽은 하늘이 채웁니다.
- 지평선(가장 먼 언덕의 윗선)은 캔버스 위에서 **약 25~35% 지점**(225~315 px)에 두는 걸 권합니다. 해가 이 근처에서 뜨고 집니다.
- 밤과 노을에는 앱이 그림 위에 남색을 살짝 덮어 어둡게 합니다. 그러니 **낮 기준의 밝은 색**으로 그려 주세요.
- 비 웅덩이처럼 날씨에 따라 달라지는 요소는 넣지 마세요. 풍경은 날씨와 상관없이 항상 같은 그림이 쓰입니다.

### 구름 `clouds/cloud-1~4.png`, `storm-1~2.png`

| 파일 | 크기 | 내용 |
|---|---|---|
| `cloud-*.png` | 약 600 × 360 px | 투명 배경에 **흰 구름 하나**. 가장자리를 번지게, 안쪽에 옅은 회색 농담을 줍니다. |
| `storm-*.png` | 약 900 × 540 px | 회색~먹색의 크고 무거운 비구름 하나. 비·눈·뇌우일 때 쓰입니다. |

- 구름이 캔버스 가장자리에서 잘리지 않게 여백을 두세요.
- 흐린 날과 밤에는 앱이 구름을 어둡게 처리하므로, **맑은 날 기준의 흰색**으로 그리면 됩니다.
- 구름 개수와 이동 속도는 실제 운량과 풍속으로 앱이 정합니다.

### 해·달 `celestial/sun.png`, `moon.png`

- **크기: 512 × 512 px**, 투명 배경
- 해·달 몸체는 **가운데에 지름 약 60%(약 307 px)** 로 그리고, 바깥 번짐·빛무리는 남은 여백 안에 담습니다.
- 달은 **보름달**로 그려 주세요. 초승달·반달 같은 모양은 앱이 실제 월령에 맞춰 그림자를 덮어 만듭니다.

### 종이 질감 `paper.png`

- **크기: 512 × 512 px**, 회색조(흰색~밝은 회색)
- 이어 붙여도 이음새가 보이지 않는 **타일형**으로 만들어 주세요.
- 앱이 화면 전체에 곱하기(multiply) 방식으로 옅게(불투명도 28%) 깝니다. 진한 얼룩은 화면 전체를 더럽게 보이게 하니 아주 은은하게 만드세요.

## 공통 규칙

- **형식**: 투명 배경 PNG (sRGB)
- **용량**: 파일 하나당 **2MB 미만**, 전체 약 5MB 이내
  - 오프라인에서도 열리도록 앱이 모든 그림을 미리 저장(캐시)하는데, 2MB가 넘는 파일은 저장되지 않습니다.
  - PNG 압축 도구(예: [TinyPNG](https://tinypng.com/), [Squoosh](https://squoosh.app/))로 줄이면 대부분 충분히 작아집니다.
- **저작권**: 직접 그린 그림이나, 상업적 이용과 수정이 허락된 무료 소스(CC0 등)만 넣어 주세요. 원작 Cloudia 앱의 그림은 pxd의 저작물이라 쓸 수 없습니다.

## 넣은 뒤 확인하는 법

```bash
npm run dev
```

브라우저에서 앱을 열고 화면을 가로로 끌어 시간을 바꿔 보세요. 낮·노을·밤에서 풍경 색이 어떻게 보이는지, 구름과 해·달 크기가 어울리는지 확인하면 됩니다. 파일이 반영되지 않으면 이름과 위치를 다시 확인하세요(브라우저 개발자 도구 Network 탭에서 404가 나는 파일을 볼 수 있습니다).

## 무료로 그리는 도구

- 지금 들어 있는 그림은 저장소 루트에서 `python scripts/generate_watercolor_art.py`로 다시 만들 수 있습니다 (Pillow 필요: `pip install pillow`, 실행하면 기존 그림을 덮어씀).

- [Krita](https://krita.org/) (무료): 수채화 브러시 기본 제공, 레이어별 PNG 내보내기 가능
- 종이 질감은 실제 수채화 종이를 스캔하거나 촬영해서 만들어도 됩니다.
